# Fortidia franchise development marketing proposal

Source repository for the Fortidia franchise recruitment marketing proposal.

## Current status

The live site was originally deployed directly to Vercel. The complete existing `index.html` must be imported here **before** Git integration is connected, to avoid replacing the current site with an incomplete version.

## Deployment

Once the complete live source has been copied into `index.html`, connect this repository's `main` branch to the existing Vercel project, keeping the existing production domain. Do not create a new Vercel project.

All lead-scoring examples, financial figures and workflows in the proposal are illustrative until validated with Fortidia.
